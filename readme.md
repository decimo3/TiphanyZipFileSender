# TiphanyZipFilePdfMerge (ZIP_BOT)

A program for consolidating PDFs contained within ZIP files.

1. Takes a filename (without extension) as an argument;
2. Searches for a ZIP file with that name within a directory;
3. Collects all PDFs from the file and merges them into a single PDF;
4. Converts the merged PDF into a base64-encoded string and writes it to standard output.

> To clarify, this program is designed for a specific use case.
